# Modelo de datos

## UNIVERSO

| Campo      | Tipo     | Ejemplo              |
|------------|----------|----------------------|
| id         | number   | 1                    |
| nombre     | string   | "Harry Potter"       |
| descripcion| string   | "El mundo mágico en papel, en el cine y en la escena"|
| color      | string   | "#4B3A8C"          |
| obras      | number[] | [1, 2, 3, 4, 5, 6]   |
